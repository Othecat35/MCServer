Semantic Versioning (MAJOR.Minor.patch):
- MAJOR: When you make incompatible API changes
- Minor: When you add functionality that is backward compatible
- patch: When you make bug fixes

The "v" Version Prefix:
- Use in:
  - Git Tag
  - Github Release
  - `mcserver --version`
  - User Agent
  - (Basically everything that a user will see)
- Don't use in:
  - Internal script version (`__version__`)
  - Changelog header
  - (Basically everything that is internal about the project)
