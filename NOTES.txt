Semantic Versioning (MAJOR.Minor.patch):
- MAJOR: When you make incompatible API changes
- Minor: When you add functionality that is backward compatible
- patch: When you make bug fixes

The "v" Version Prefix:
- Use in:
  - Git Tag
  - Github Release
  - `mcserver --version`
  - User Agent
  - (Basically everything that a user will see)
- Don't use in:
  - Internal script version (`__version__`)
  - Changelog header
  - (Basically everything that is internal about the project)

MCServer™ Naming Convention: (the Trademark is just a joke)
- is_*
  The value is true or false
  - Examples:
    - is_featured
    - is_primary
- filename
  Full file name with extension
- file_path
  The path of a file (relative to current working directory)
- download_url
  URL that can be downloaded
- *_count
  Return a number of something
  - Examples:
    - download_count
    - follower_count
- file_size
  The size of the file in byte
- file_hashes
  A hash or multiple hashes of the file
- *_url:
  Its an URL.
  - The `get_`
